# Hypothyroid Classification

Hypothyroid Classification is a Machine Learning project that predicts whether a patient is likely to have hypothyroidism based on medical and laboratory test data. The project focuses on data preprocessing, exploratory data analysis, feature engineering, model training, and performance evaluation.

## Dataset

The project uses the Hypothyroid dataset containing patient medical records and laboratory test results.

Key attributes include:

* Age
* Sex
* TSH
* T3
* TT4
* T4U
* FTI
* Medical history indicators

Target Variable:

* Binary Classification (Hypothyroid / Not Hypothyroid)

## Machine Learning Workflow

1. Data Collection
2. Data Cleaning
3. Missing Value Treatment
4. Exploratory Data Analysis
5. Feature Engineering
6. Model Training
7. Model Evaluation
8. Performance Comparison

## Results

The trained models were evaluated on unseen test data. Among all models, CatBoost achieved the best overall performance and provided highly accurate classification results for hypothyroid prediction.
